# 图片替换功能使用指南

## 功能概述

图片替换功能允许你在 PDF 渲染时，将 AP-Form 中的图片临时替换为外部图片。这在需要动态修改表单图片内容时非常有用，例如：
- 替换签名图片
- 更新表单中的照片
- 测试不同图片的显示效果

**重要**: 替换是临时的，不会修改原始 PDF 文件。

## 快速开始

### 1. 启动应用

运行应用后，你会在底部状态栏看到一个 **"选择替换图片"** 按钮。

### 2. 选择替换图片

1. 点击 **"选择替换图片"** 按钮
2. 在文件选择对话框中选择一张图片（支持 PNG/JPG/JPEG）
3. 点击 **"打开"**

### 3. 查看效果

- 图片加载成功后，会显示确认提示
- 按钮标题变为 **"清除替换"**
- 当前页面会自动重新渲染，显示替换后的效果

### 4. 清除替换

点击 **"清除替换"** 按钮，恢复显示原始图片。

## 状态栏布局

```
[页码控件] [缩放控件] [启用水印] [选择替换图片/清除替换]
```

## 替换模式说明

当前实现支持 **全局替换** 模式：
- 所有 AP-Form 中的图片都会被替换为你选择的图片
- PDFium 会自动处理图片缩放和适配

## 与水印功能的配合使用

图片替换和水印可以同时使用：

1. **先替换后水印**：替换的图片会先应用，然后在替换后的图片上叠加水印
2. **独立控制**：两个功能可以独立开启/关闭

示例工作流程：
```
原始图片 → [图片替换] → 替换后的图片 → [水印叠加] → 最终显示
```

## 技术细节

### 内存管理

- PDFium 会创建外部图片的内部副本
- 图片选择后可以安全地删除或移动源文件
- 不会影响 PDF 原始数据

### 性能考虑

- 图片替换仅在渲染时发生
- 不影响 PDF 加载速度
- 大图片可能会增加渲染时间

### 支持的图片格式

- **PNG**: 完全支持，包括透明通道
- **JPEG/JPG**: 完全支持

## 常见问题

### Q: 为什么选择的图片没有显示？

A: 可能的原因：
1. 当前 PDF 页面没有 AP-Form 图片对象
2. 图片格式不支持（目前仅支持 PNG/JPG）
3. 图片文件损坏或无法读取

### Q: 替换的图片尺寸需要与原图相同吗？

A: 不需要。PDFium 会自动使用原图的变换矩阵来缩放和定位替换图片。

### Q: 可以为不同的图片对象设置不同的替换图片吗？

A: 当前版本仅支持全局替换（所有图片使用同一张替换图片）。如需条件替换或映射替换，请参考开发者文档。

### Q: 替换会修改原始 PDF 文件吗？

A: 不会。替换仅在渲染时生效，不会修改磁盘上的 PDF 文件。
